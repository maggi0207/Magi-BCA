Comment
As discussed with Laura and Mahendra, this is a new change request from the user. I do not want to modify the original user story description, so I am documenting the requested enhancement in the comments section. Please review and validate the following changes for this ticket.

Ticket Title
State License Section Should Prepopulate Existing License Records and Allow Editing

Description
Currently, when a provider record contains existing State License information, the State Licenses section does not prepopulate the previously saved records. Users are required to re-enter license information instead of updating existing details.
The application should automatically populate all existing State License records when the page is opened in Edit mode. Users should be able to review and modify the prepopulated information as needed.

Acceptance Criteria
Existing State License records are automatically displayed when editing a record.
All previously saved license field values are prepopulated.
Users can edit and update:
State
Effective Date
License Number
Status
Expiration Date
Field of Licensure
Updated values are saved and persist after refresh/reopening the record.
No duplicate license records are created during the update process.
Expected Behavior
When a user opens an existing provider/application record, the system should:

Retrieve and display all existing State License records.
Prepopulate the following fields with saved values:
State
Effective Date
License Number
Status
Expiration Date
Field of Licensure
Allow users to edit any of the prepopulated fields.
Save updates successfully without requiring a new license record to be created.

Comment : Expected :

If the entered Expiration Date is earlier than the current date, the system should display a warning message:

"The expiration date entered is in the past. Are you sure you want to continue?"

An expired license date triggers a warning message, not a validation error.
Users are not blocked from continuing when an expired license is entered.
Selecting Yes on the warning message allows the process to continue and creates a CVI.
