Quote (`ShouldRequireField`):
```csharp
public static ValidationResult ShouldRequireField(string value, ValidationContext validationContext)
{
    var model = validationContext.ObjectInstance as NewPractitionerModel;
    if (value == null && !model.IsRecruitmentRole)
        return new ValidationResult("Required field.", new[] { validationContext.MemberName });
    return ValidationResult.Success;
}
```
