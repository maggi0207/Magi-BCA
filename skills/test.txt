User Story: State License-Specific PSV Upload and Global PSV Sharing
Title: Enable independent License PSV uploads for each State License and shared/global Sanction PSV and NPI PSV uploads

User Story
As a Credentialing Specialist,

I want to upload a separate License PSV document for each individual state license while maintaining a single shared Sanction PSV and NPI PSV document across all licenses,

So that license verifications can be managed independently per state while avoiding duplicate uploads for provider-level verifications such as Sanctions and NPI.

Business Requirement
Currently, License PSV, Sanction PSV, and NPI PSV are uploaded within the same workflow when adding an NPP provider.

The system shall:

Associate License PSV with the selected State License only.
Allow a unique License PSV document for each State License.
Treat Sanction PSV as a provider-level document shared across all State Licenses.
Treat NPI PSV as a provider-level document shared across all State Licenses.
Automatically display previously uploaded Sanction PSV and NPI PSV documents when users navigate between State Licenses for the same practitioner.
Acceptance Criteria
AC1: License PSV is State License specific
Given a practitioner has multiple state licenses

When the user selects a State License

And uploads a License PSV document

Then the uploaded document shall be associated only with the selected State License

And shall not appear under any other State License.

AC2: Different License PSV documents can be uploaded
Given a practitioner has licenses in Wisconsin, California, and Florida

When the user uploads a unique License PSV document for each license

Then the system shall save and display the corresponding License PSV document for that specific State License.

AC3: Sanction PSV is shared globally
Given a Sanction PSV document has been uploaded for the practitioner

When the user switches between State Licenses

Then the same Sanction PSV document shall be displayed across all State Licenses

And the user shall not be required to upload the document again.

AC4: NPI PSV is shared globally
Given an NPI PSV document has been uploaded for the practitioner

When the user switches between State Licenses

Then the same NPI PSV document shall be displayed across all State Licenses

And the user shall not be required to upload the document again.

AC5: Update shared documents
Given a shared Sanction PSV or NPI PSV document already exists

When the user uploads a replacement document

Then the new document shall replace the existing shared document

And the updated document shall be reflected across all State Licenses.

AC6: Validation
Given License PSV is mandatory

When a State License is selected

And no License PSV has been uploaded for that license

Then the system shall display an appropriate validation message preventing submission.

And

Given Sanction PSV and NPI PSV are mandatory

When neither document exists at the provider level

Then the system shall require upload before submission.
