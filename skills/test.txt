**2. NPP Gates**

For a completed NPP task, the existing sanction operation still runs first, followed by the new state-license operation. The state-license logic uses `NPDBSTATEx` and checks duplicates by provider, license type, state, and number. Active practitioners with a matching license are not updated; the license can still receive the submitted PSV attachment. Missing licenses are inserted, then their PSV is attached using `D2B50K69Z8` and queued for conversion.

The shared key-returning insert helper now accepts optional NPP status, award/expiration dates, licensure field, and primary-license values. Defaults for existing callers remain unchanged.
