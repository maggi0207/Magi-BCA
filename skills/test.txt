**PafFile reuse**
Each upload uses the existing `PafFile`, the NPP task’s `TaskId`, and the existing generic `Other` attachment type. For example:

```razor
<PafFile Attachment="@context.LicensePsvAttachment"
         FormType="PractitionerActionFormAttachmentType.Other"
         TaskId="@context.TaskId"
         OnAfterUpload="HandleLicensePsvUpload"
         OnAfterRemove="HandleLicensePsvRemove" />
```

`PafFile` requires a `FormType` and accepts `.pdf`, `.doc`, `.docx`, `.jpg`, `.jpeg`, `.tif`, and `.tiff` (`PafFile.razor.cs:33`). The existing enum contains `Mss18Form`, `AAR`, `Dop`, and `Other`, but no License/Sanctions/NPI PSV types (`PractitionerActionFormAttachment.cs:30`). I used `Other`; no enum values were added. Upload/remove callbacks save or clear each `PafAttachment` on `NppTask` and update the corresponding required-validation field.

**Visibility and required rules**
The existing State License condition controls License PSV visibility and requiredness:

```csharp
nameof(LicensePsvAttachmentUrl) => ShouldShowStateLicenses(task),
nameof(SanctionsPsvAttachmentUrl) or
nameof(NpiPsvAttachmentUrl) => true,
```

Thus License PSV is hidden and not required for VA=Yes/PA=Yes; Sanctions and NPI PSV remain shown and required. When State Licenses are shown, all three PSV uploads are required (`NppTask.cs:52`, `NppTaskForm.razor:180`).
