**Review NPP**

The review renders the NPP section only when the selected task is NPP and its task data exists:

```razor
<ReviewNppTask Task="@_nppTask" PractitionerKey="@_practitionerAtLastLoad?.Key"
               OnRequestEdit="() => OnRequestEdit.InvokeAsync(TaskType.Npp)">
```

`LoadData()` supplies it with `_nppTask = state.NppTask;`. The read-only summary shows VA and applicable PA answers, the selected license or new-license details, and License/Sanctions/NPI PSV categories with uploaded file names. Existing-license details are looked up by the saved key. Delegate, Add-Practitioner, MSS-18, and MSS-18 FSQ remain hidden for NPP.

**Address Validation**

For NPP, completion now requires only a confirmed Primary; missing Primary opens the existing Save for Later flow. Hidden Home, Credentialing, and Alternate collections are not read or checked in that NPP branch. Non-NPP client validation remains on its original path.

The processor basis is that `CactusUpdater` processes each address collection only when it is non-null and non-empty; it does not require Home or Credentialing. I also aligned submit-time API revalidation: NPP still revalidates Primary, but skips the hidden Home, Credentialing, and Alternate checks that otherwise would reject the Primary-only task.
