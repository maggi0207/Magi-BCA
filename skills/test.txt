Implemented NPP sanction record creation and sanctions PSV image handling.

**Files changed**

- `CrudPractitionerLicensesOperation.cs`
- `CactusUpdater.cs`
- `CactusOperationIntegrationTests.cs`

For completed NPP tasks, the license operation now looks up `S3PK02GTA1` by provider and license type, reuses an existing record, or inserts one if absent. It then creates the sanctions image through the existing `CrudImagesOperation` provider-license path, using the ticket’s `S3PK02WN8H`, the requested description and notes, and queues the PAF attachment for conversion. A missing attachment logs a warning; image creation errors are caught and logged. The existing-provider CactusUpdater path now invokes the license operation for completed NPP tasks.
