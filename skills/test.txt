### Where `CanBeginPaf` comes from

Not computed inside `PafQueueSearchCriteria` — it is a passed-in parameter. Supplied by the parent, `PafQueueSearch.razor` (line 13):

```razor

```

`PafQueueSearch.razor.cs` (line 129):

```csharp
private bool CanBeginPAF()
{
    if (IsMspUser() || IsRecruitmentUser())
        return true;
    else return false;
}
```

`IsMspUser()`/`IsRecruitmentUser()` delegate to `_currentUser` (a `ClaimsPrincipal`), via extension methods in `Shared/Extensions/PrincipalExtensions.cs`:

- `IsMspUser()` → `IsInRole("Msp") || IsInRole("Psg")`
- `IsRecruitmentUser()` → `IsInRole("Recruiter") || IsInRole("RecruiterManager")`

## 5. `MspDashboardPage` Relationship to MSP/PSG

- Routes: `@page "/Msp/Dashboard/{NavigateTab?}/{QueueType?}"` and `@page "/Psg/Dashboard/{NavigateTab?}/{QueueType?}"` (same component serves both routes).
- `@attribute [Authorize(Roles = "Msp, Psg")]`.
- In `OnInitializedAsync()`: `_pageTitle` is set to `"PSG Dashboard"` if `_currentUser.IsPsgUser()`, else `"MSP Dashboard"` if `IsMspUser()`, else `"Dashboard"`. Since `IsMspUser()` itself returns true for either the `Msp` or `Psg` role, PSG users are treated as a variant of MSP for this page, distinguished only by title text.
