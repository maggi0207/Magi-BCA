Implemented the public practitioner state-license listing path.

1. **Files changed**
   - `PractitionerLicenseRepository.cs`
   - `PractitionerLicenseController.cs`
   - `PractitionerLicenseClient.cs`

2. **Method, route, and SQL**
   - Repository/client method: `GetPractitionerStateLicensesAsync(string practitionerKey)`
   - Route: `[HttpGet("{practitionerKey}/StateLicenses")]`
   - SQL filter: `WHERE pl.PROVIDER_K = @PractitionerKey AND pl.LICENSE_RTK = @LicenseRtk`, with `LicenseRtk = "NPDBSTATEx"`.
   - The query has no `ACTIVE` or `STATUS_RTK` filter. It maps selected existing license columns into the shared `PractitionerLicense` DTO.
