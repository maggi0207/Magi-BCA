   ```csharp
   searchParams.SearchType = PractitionerSearchType.Simple;
   searchParams.Npi = _npiInputMask?.RawValue ?? _npiInputMaskNonRecruitment?.RawValue;
   ```
   The form also keeps the NPI in the two-way-bound `_model.PractitionerNpi`. If the mask value is empty, the request reaches Simple without an NPI, which fails the Simple search criteria check and can appear as no results. The exact runtime request wasn’t captured, so the missing mask value is the identified failure path, not a network-confirmed observation.
