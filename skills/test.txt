**2. Gate and Parent**

For completed NPP tasks, NPI attachment processing now follows sanction and state-license processing. It reads `NppTask.NpiPsvAttachment`; if absent, it logs a warning. The image uses `ParentFileK = ImageParentFileKValues.Provider` and `ParentK = PractitionerKey`, making it provider-level rather than license-level.

The helper uses type `D2MQ0MQHOY`, description `{LastName13}_{FirstName3}_NPI_MMDDYY`, notes `Uploaded via auto PAF for ADD NPP to Facility`, and a generated original filename consisting of that description plus the uploaded file’s extension. It queues the attachment ID for the existing conversion worker, which retrieves the actual bytes from the PAF attachment store. Attachment/image exceptions are logged and do not fail the NPP processing operation.
