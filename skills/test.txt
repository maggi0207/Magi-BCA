132608 NPP: Entity Assignment Record
Feature 2: Create and Maintain Entity Assignment Records
Description

Create and update Entity Assignment records associated with the facility selected on the PAF.

Included Functionality
Create assignment for net-new practitioners.
Apply security rules.
Set status when appropriate.
Preserve historical privilege records.
Business Rules
Record security defaults to Internal Use Only.
Do not modify inactive entity assignments with historical start/end dates.
Status defaults to NPP – Active when not currently populated.
Status updates only occur when current status is:
None
N/A
NPP – Inactive
NPP – Suspend
Inactive
Acceptance Criteria
Assignment record is created for selected facility.
Internal Use Only security is applied.
Existing privilege history remains unchanged.
Status updates follow defined rules.
Invalid statuses are not overwritten.
Exception Handling
Facility not found → log error and stop assignment creation.
Duplicate assignment detected → update per existing logic rather than create duplicate.


132622 NPP: Entity Assignment Record
User Story 2.1 – Create Entity Assignment for Net-New Practitioner
As an MSP
I want an Entity Assignment record automatically created
So that practitioners are associated to the selected facility.

Acceptance Criteria
Given a net-new practitioner
When a PAF is accepted
Then an Entity Assignment record is created for the facility selected on the PAF.

And security is set to Internal Use Only = ENTITYASSIGNMENTS_WEBPUBLISHSTATUS_RTK:RECFLT_INT

Exception Handling
Invalid facility mappings generate errors.
Duplicate assignments are prevented.
