Implemented for **NPP exception search only**. Classic Begin PAF, Recruitment, and PSG search behavior is unchanged.

**First Name**
In `PractitionerSearchForm.razor`, the existing input was:
```razor
<FormItem Label="First Name">
    <ChildContent>
        <InputHca Id="practitionerFirstName" @bind-Value="@_model.PractitionerFirstName"
                  Placeholder="Enter first name" TValue="string"
                  OnChange="@OnFieldChanged" Disabled="@(!_practitionerFirstNameEnabled)"
                  DebounceMilliseconds="0"/>
```

It now uses `Required="@IsNppRequest"` to show the asterisk.

Previously, NPP Search enabled with only:
```csharp
return !string.IsNullOrWhiteSpace(_model.PractitionerLastName);
```

It now uses `SearchModel.IsValidNppExceptionCriteria(...)`, requiring nonblank alphabetic First Name, at least two alphabetic Last Name characters, and a valid optional State/License pair. The existing message is reused:
> Must be a minimum of 1 alpha characters

`PractitionerSearchParameters.cs` now rejects blank First Name in `ValidateForNppExceptionSearch()` too. NPP NPI searches remain exempt from the First Name requirement.

**State Dropdown**
The ADD NPP reference in `NppTaskForm.razor` is:
```razor
<Neutron.Blazor.Components.Select Id="nppNewLicenseState" DataSource="@_states"
                                  @bind-Value="@context.NewLicenseState"
                                  ValueName="@nameof(FieldOption.Value)"
                                  LabelName="@nameof(FieldOption.Text)">
</Neutron.Blazor.Components.Select>
```
Its list is `private readonly ICollection<FieldOption> _states = OptionConstants.States;`.

The exception form now uses that same component and option list, bound to `_model.State`. `FieldOption.cs` contains:
```csharp
new FieldOption { Value = "TX", Text = "Texas" }
```
The stored value is **`"TX"`**, not `"Texas"`.

`NppExceptionSearchPagedQueryBuilder.cs` sends:
```csharp
where.Parameters.Add("@State", searchParameters.State.Trim(), DbType.String);
```
and compares `PL.STATE = @State`. The values match; no mapping or query change was needed.
