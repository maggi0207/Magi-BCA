| Severity | File / method | Issue and why it matters | Suggested fix |

A net-new NPP with no hidden-category addresses cannot complete this optional task after editing only the visible Primary section. | `ManageAddressesTask.ValidateAndSaveAddresses` |
| **Minor** | `SubmitPafStrategy.ProcessSubmitForMspAsync` | For non-NPP PAFs, Delegate revalidation moved ahead of Add Privileges and Collaborating Practitioners; the same calls remain, but their order changed. The core checklist otherwise looks sound: NPP submit gets authenticated `_user` values for `IsMspUserMode` and `UserId`; NPP VA-No dispatches to `ProcessSubmitForMspAsync`; VA+PA Yes does not call SSP Brief; `CreateAddTaskStrategy(Npp)` remains `AddTaskAddPractitionerToFacilityStrategy`; Review hides the three specified legacy cards; the new PafFile controls use `FormType.Other` and the existing callbacks. `HCA0095563` and `UDP0000001/2` match the supplied product values. Facility category IDs in the new query already occur in existing repository queries, and `NPDBSTATEx` is already used in the codebase. I found no apparent credentials added in changed tracked lines.
