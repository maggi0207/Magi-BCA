Implemented the NPP-only card and Work form.

1. **Files changed for this feature:** `NppTask.cs`, `PractitionerActionFormData.cs`, `StateContainer.cs`, `PafTaskDisplay.razor.cs`, `PafFormComponent.razor`, `PafFormComponent.razor.cs`, `NppTaskForm.razor`, `NppTaskForm.razor.cs`, `PafProcessingStrategyContext.cs`, and `UpdateTaskNppStrategy.cs`. The PAF component files also contain earlier, unrelated worktree changes; those were left intact.

2. **Card visibility:** `StateContainer.PafState.TaskSelected == TaskType.Npp ? "paf-card" : "hide"`. It uses the NPP task when present or a required display placeholder when an older saved NPP PAF has no NPP task object. The title and description use the exact supplied copy.

3. **Work target:** `HandleRequestEditAsync` maps `TaskType.Npp` to `PractitionerPafViewState.Npp`, which renders `NppTaskForm`. It does not open FSQ.

4. **VA/PA and license visibility:** VA No shows state licenses. VA Yes shows PA; licenses remain hidden until PA is answered. PA Yes hides licenses; PA No shows them. Save requires a VA answer and, when VA is Yes, a PA answer.

5. **License client call:** `CactusClient.PractitionerLicenses.GetPractitionerStateLicensesAsync(practitionerKey)`, using `StateContainer.PafState.Practitioner?.Key`. The list displays State, License Number, and Expiration Date without client-side Active filtering. “Add New State License Instead” remains selectable even when the API returns no rows. API errors use the existing `NotificationService` pattern.

6. **Update strategy:** `TaskType.Npp => new UpdateTaskNppStrategy(this, reloadAndRevalidate)` persists the NPP task and validates its required VA/PA answers. Save uses the existing PAF update path; it does not submit.

7. **Protected paths unchanged:** `CreateAddTaskStrategy(Npp)` remains mapped to `AddTaskAddPractitionerToFacilityStrategy`. `GetCredentialingTypeRtk`, submit/CVI processing, FSQ, and the facility-add strategy were not changed.

8. **Builds:** Client/Shared Release build succeeded; PAF API Release build succeeded. `git diff --check` passed. Editor diagnostics reported no errors in the new strategy or relevant component code.

9. **Remaining gaps:** The “Add New State License Instead” option is selectable but has no entry form. STATUS/FOL fields and PSV uploads are not implemented. This change does not submit the PAF or create a CVI.
