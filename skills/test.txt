Implemented the NPP-only demographic optional-field change.

1. **Files changed**
- `PafFormComponent.razor`
- `ManagePractitionerInformationTask.razor.cs`

2. **NPP isolation source**

`PafState` has no `Type` property, so the parent passes a boolean using the persisted selected task:

```razor
IsNppPaf="@(StateContainer.PafState.TaskSelected == TaskType.Npp)"
```

The task receives it as:

```csharp
[Parameter] public bool IsNppPaf { get; set; }
```

3. **Flags and validation**

The model receives the signal:

```csharp
_model.IsNppPaf = IsNppPaf;
```

The five required flags become optional only for recruitment or NPP:

```csharp
if (_model.IsRecruitmentRole || _model.IsNppPaf)
{
    _dobRequired = false;
    _genderRequired = false;
    _ssnRequired = false;
    _emailRequired = false;
    _phoneNumberRequired = false;
}
```

Blank-field validation is bypassed only for those modes:

```csharp
if (string.IsNullOrEmpty(value)
    && !model.IsRecruitmentRole
    && !model.IsNppPaf)
```

Existing populated-value validators remain unchanged. First Name, Last Name, Degree, Category, Suffix, Middle Name, and NPI behavior were not changed.
