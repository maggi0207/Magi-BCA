132591: NPP: Auto-Acceptance and Automated Processing
ADD NPP PAF Auto-Acceptance and Automated Processing
Epic Title: Automate ADD NPP PAF Acceptance, Audit Tracking, and Document Attachment Management

Business Objective:
Eliminate CPC review requirements for standard ADD NPP PAF submissions by leveraging auto-acceptance capabilities while maintaining proper audit tracking, processing visibility, and document management for both standard and exception workflows.

Business Value:

Reduces CPC workload and processing time.
Accelerates provider onboarding and updates.
Standardizes audit and history records for auto-accepted PAFs.
Ensures proper document storage based on processing path.
Supports exception-based CPC workflows through CVI integration.
Description:
The system shall automatically accept all ADD NPP PAF submissions without CPC review unless the submission meets criteria that trigger an exception workflow requiring CPC processing and CVI creation. Following successful Cactus processing, the PAF shall be routed to the Completed Queue, audit records shall be updated appropriately, and the PAF PDF shall be attached to either the Provider Record or the associated CVI based on workflow outcome.



Rule ID

Rule Description

BR-001

All ADD NPP PAFs shall be auto-accepted.

BR-002

CPC review is not required for auto-accepted ADD NPP PAFs unless exception workflow criteria are met.

BR-003

Auto-accepted PAFs shall route to the Completed Queue only after successful Cactus processing.

BR-004

Auto-Accepted PAF History shall record "HCP System User" as the User Name.

BR-005

Cactus Audit Log User value shall be "HCP System User – MSP Submitter Name".

BR-006

Cactus Audit Log Entity value shall be "HCA Corporate".

BR-007

PAF PDFs shall be attached to the Provider Record when no CVI exists.

BR-008

PAF PDFs shall be attached to the CVI when a CVI is created through an exception workflow.
