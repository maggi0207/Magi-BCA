**2. Gate / Existence Rule**

Added a check before `CrudAddressOperation` in both updater address loops. It applies only when `TaskSelected == TaskType.Npp` and the address type is `CommonCactusRtks.PrimaryAddressTypeRtk`. The query checks for any active, non-ended Primary association for that provider:

> `PROVIDER_K = @ProviderK`  
> `AND ADDRESSTYPE_RTK = @AddressTypeRtk`  
> `AND ACTIVE = 1`  
> `AND TODATE IS NULL`

A match causes the updater to `continue`, skipping both address creation and provider-address update. With no match, the existing creation flow proceeds.
