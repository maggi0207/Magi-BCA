132678 NPP: Sanction Check

Feature 7: Create Sanction Check Records and Attachments
Description

Create Sanction Check records and attach sanctions documentation when records do not already exist.

Included Functionality
Sanction record lookup.
Record creation.
Image attachment.
Business Rules
Check for existing Sanction Check record:
LICENSE_RTK.PROVIDERLICENSES = S3PK02GTA1
Create record if none exists.
Attach sanctions image from PAF.
Image Standards
Name IMAGES_DESCRIPTION

 
{LastName13}_{FirstName3}_Sanctions_MMDDYY 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
Type  IMAGES _TYPE_RTK S3PK02WN8H

 
Sanction Checks 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
Notes IMAGES_NOTES

 
Uploaded via auto PAF for ADD NPP to Facility 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
Acceptance Criteria
Existing sanction records are not duplicated.
New sanction records are created when absent.
Image attached successfully.
Naming standards followed.
Exception Handling
Missing sanction document.
Duplicate sanction record detected.
Attachment failure logged.
