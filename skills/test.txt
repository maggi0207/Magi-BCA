**C. Required flags and NPP isolation**

`OnInitializedAsync()` currently changes required flags only for recruitment:

```csharp
_model.IsPsgRole = currentUser.IsInRole(nameof(HcoApplicationRole.Psg));
_model.IsRecruitmentRole =
    (StateContainer.PafState.RecruitmentPsvTask != null ||
     currentUser.IsRecruitmentUser());

if (_model.IsRecruitmentRole)
{
    _dobRequired = false;
    _genderRequired = false;
    _ssnRequired = false;
    _emailRequired = false;
    _phoneNumberRequired = false;
}
else
{
    _dobRequired = true;
    _genderRequired = true;
    _ssnRequired = true;
    _emailRequired = true;
    _phoneNumberRequired = true;
}
```

There is no `TaskType.Npp`, `PafType`, or Begin NPP branch in this component. `PafFormComponent` passes no NPP parameter to it.

**Gap:** NPP optional-field isolation does not currently exist on this form.
