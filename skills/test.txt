2. **Period and inclusive dates**

   The function uses the requested timer expression:

   ```csharp
   [TimerTrigger("0 0 8 1 * *", UseMonitor = false)]
   ```

   It calculates the prior month’s first day and the current month’s first day as an exclusive bound:

   ```csharp
   var currentMonthStart = new DateTime(date.Year, date.Month, 1, 0, 0, 0, date.Kind);
   return (currentMonthStart.AddMonths(-1), currentMonthStart);
   ```

   The query uses `IndexedSubmittedDate >= @PeriodStart` and `< @PeriodEndExclusive`, which includes the entire prior month, including its last day. The displayed period ends on `EndExclusive.AddDays(-1)`.

4. **CVI-created detection**

   The report counts each matching PAF once when its stored `FormData` JSON contains at least one `CreatedOrUpdatedCvis` item:

   ```sql
   FROM OPENJSON(paf.FormData, '$.CreatedOrUpdatedCvis')
   ```

   This reuses the existing persisted collection: CactusUpdater loads the affected `CREDENTIALING_K` records into `CviSummaryResult` values, and `PafDataContext.UpdatePaf` stores them in `CreatedOrUpdatedCvis`. The NPP Cactus path inserts the NPP `CREDENTIALING` record. The query does not invent a new flag or join.
