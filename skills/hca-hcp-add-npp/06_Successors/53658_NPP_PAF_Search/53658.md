## Description

The Practitioner Search workflow within HCP enforces the National Provider Identifier (NPI) as the primary and required search criterion.

Users must enter a valid 10-digit NPI before a standard practitioner search can be performed. A controlled exception workflow is available when an NPI is unavailable.

This feature will leverage the existing Enforce NPI Search workflow when users select **Begin NPP PAF** from the MSP Dashboard, ensuring a consistent practitioner search experience for Non-Privileged Practitioner (NPP) requests.

## Dependency

This feature is dependent upon the completion and deployment of **Epic 136871**.

**Epic 136871 must be completed before development, testing, or deployment of this feature can begin**, as it provides the foundational Enforce NPI Search functionality required for this enhancement.

Do not start Copilot implementation of `53658` / `127104` until `136871` (and its children `136872`, `136873`, `136876`, `136878`, `136882`, `136883`) is treated as complete, unless the user explicitly overrides this ticket dependency.

## Acceptance Criteria

### Scenario 1 — Begin NPP PAF Routing

Users selecting **Begin NPP PAF** are routed to the existing **Enforce NPI Search** workflow.

### Scenario 2 — NPI Required

The Practitioner Search workflow requires a valid **10-digit NPI** before a standard practitioner search can be performed.

### Scenario 3 — NPI Unavailable

Users without an available NPI are directed through the existing controlled exception workflow.

### Scenario 4 — Reuse Existing Search

Existing Enforce NPI Search functionality is reused.

No duplicate search logic is introduced.

### Scenario 5 — Existing Begin PAF

Existing **Begin PAF** functionality remains unchanged.

### Scenario 6 — Dependency

**Epic 136871** must be completed and deployed prior to implementation and testing of this feature.
