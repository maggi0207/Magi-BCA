## 2. User Story

Not labeled as a user story on the captured feature. Intent from the description:

MSP users need a dedicated PAF Action **ADD NPP to Facility** for a net-new practitioner or an existing practitioner who is inactive with the selected entity, reusing existing task determination and keeping a single action selected.

## 3. Description

Add a new PAF Action radio button labeled **ADD NPP to Facility**.

Enable MSP users to add a Net New Practitioner (NPP) or an inactive existing practitioner to a facility through that option while leveraging existing PAF task determination rules and maintaining role-based access controls.

## 4. Acceptance Criteria

From the feature paste (no numbered Given/When/Then in the export):

1. Radio visible **only** to users assigned the **MSP role**.
2. Available only when the selected practitioner is:
   - a **net new practitioner**, or
   - an **existing practitioner currently inactive with the selected entity**.
3. Use **existing PAF task determination rules**.
4. Allow **only a single PAF Action** selection.

Visibility:

```text
MSP role
   AND
eligible practitioner
   ↓
ADD NPP to Facility is visible
```

Exact label: **ADD NPP to Facility**
