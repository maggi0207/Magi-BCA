## User Story

> As an MSP user, I want the **"ADD NPP to Facility"** option available only for eligible practitioners so that invalid facility assignments cannot be initiated.

## Description

The **"ADD NPP to Facility"** option should only be displayed when the practitioner meets one of the following eligibility conditions:

- **Net New Practitioner**
- **Existing Practitioner with an inactive relationship to the selected entity**

The option must not be displayed for practitioners who do not meet the eligibility requirements.

## Acceptance Criteria

### Scenario 1: Net New Practitioner

**Given** the practitioner is identified as Net New

**When** the Practitioner Action section loads

**Then** the **"ADD NPP to Facility"** option is displayed.

### Scenario 2: Existing Inactive Practitioner

**Given** the practitioner exists in the system and is inactive with the entity

**When** the Practitioner Action section loads

**Then** the **"ADD NPP to Facility"** option is displayed.

### Scenario 3: Active Practitioner

**Given** the practitioner is active with the entity

**When** the Practitioner Action section loads

**Then** the **"ADD NPP to Facility"** option is not displayed.

### Scenario 4: Ineligible Practitioner Status

**Given** the practitioner does not meet eligibility requirements

**When** the Practitioner Action section loads

**Then** the option is hidden.

## Eligibility Logic

```text
                    ┌── Net New Practitioner ───────────→ SHOW
                    │
Practitioner ───────┤
                    │
                    └── Existing + Inactive with Entity → SHOW
                    │
                    └── Existing + Active with Entity ─→ HIDE
                    │
                    └── Other Ineligible Status ───────→ HIDE
```
