## User Story

### As an MSP user

I want the existing **Begin PAF** process to remain unchanged

So that standard practitioner requests continue to function normally.

## Description

Ensure the addition of **Begin NPP PAF** has no impact on the existing PAF initiation workflow.

## Acceptance Criteria

### Scenario 1

**Given:** The existing MSP Dashboard is displayed.

**When:** The user selects **Begin PAF**.

**Then:** The current Begin PAF workflow is launched.

### Scenario 2

Existing practitioner search options remain unchanged.

### Scenario 3

Existing validations remain unchanged.

### Scenario 4

Regression testing confirms there are no unintended changes.

- Regression testing

## Functional Understanding

This story defines the **regression boundary** for introducing the new NPP entry point.

The new feature must not change the behavior of the existing standard practitioner PAF workflow.
