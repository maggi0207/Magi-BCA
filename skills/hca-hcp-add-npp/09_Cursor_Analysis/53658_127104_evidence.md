## 6. Exception-search audit — **STOP** (not B)

### 6.1 Ticket requirement

Out of scope: new audit architecture / schema.  
Do not invent `AuditAction`.

### 6.2 Execution path

```text
PractitionerSearchForm.OnFinish()
    → searchParams.SearchType = PractitionerSearchType.Recruitment   (line 267)
    → SearchExistingPractitionersAsync(...)
    → PractitionerRepository.SearchPractitionersAsync(searchParameters, userId)
```

### 6.3 What already audits

In `SearchPractitionersAsync`, **only** `PractitionerSearchType.AffiliationVerification` queues audit:

```csharp
await _serviceBusService.QueueAuditLogEntry(
    _auditLogger.GetAffVerifyPractitionerSearchAuditLog(
        searchParams.PractitionerId, searchParams.FirstName, searchParams.LastName,
        searchParams.Npi, searchParams.Ssn, searchParams.DateOfBirth));
```

Pipeline (reusable **infrastructure**, not a reusable **event** for this case):  
`ICredentialingAuditLogger` + `IServiceBusService.QueueAuditLogEntry(AuditLog)`.

`GetAffVerifyPractitionerSearchAuditLog` is Affiliation-Verification-specific. **Do not reuse** it for NPP/exception search because the parameter list fits.

### 6.4 Why a Recruitment-branch hook is unsafe

Callers that set `SearchType = PractitionerSearchType.Recruitment`:

| Caller | File | In 53658/127104 audit scope? |
|---|---|---|
| Exception-search submit | `PractitionerSearchForm.OnFinish()` line 267 | Yes |
| Duplicate check | `PractitionerDuplicateCheckHelper.FindDuplicatesForRecruitment` lines 94 and 127 | **No** — “Do not audit Add New Practitioner” |

Both hit the **same** server branch:

`PractitionerRepository.SearchPractitionersAsync` → `else if (searchParameters.SearchType == PractitionerSearchType.Recruitment)` (line 104).

`PractitionerSearchParameters` has **no** field that means “user exception search” vs “system duplicate check”.  
`Pager.Next` (`10` vs table `pageSize`) is incidental — **not** a discriminator. Do not key audit on it.

Auditing the entire Recruitment branch would also log duplicate checks during Add New Practitioner / demographics.
