## Business Objective

Enable MSP users to add a Net New Practitioner (NPP) or an inactive existing practitioner to a facility through a dedicated PAF Action option while leveraging existing PAF task determination rules and maintaining role-based access controls.

## Business Value

- Streamlines practitioner onboarding and reactivation workflows.
- Provides MSP users with a dedicated action for facility assignments.
- Ensures consistency by reusing existing PAF task determination logic.
- Reduces manual workarounds and improves operational efficiency.

## Feature Description / Functional Description

Add a new PAF Action radio button labeled:

> **ADD NPP to Facility**

The option must:

1. Be visible **only to users assigned the MSP role**.
2. Be available only when the selected practitioner is either:
   - A **net new practitioner**, or
   - An **existing practitioner currently inactive with the selected entity**.
3. Use the **existing PAF task determination rules**.
4. Allow only a single PAF Action selection.

## Acceptance Criteria

Captured from the feature text (scenario IDs were not in the paste):

- New radio **ADD NPP to Facility** exists in PAF Action.
- Visible only for MSP role **and** eligible practitioner (net new, or existing inactive with the selected entity).
- Existing PAF task determination rules are reused (no new determination engine).
- Only one PAF Action can be selected at a time.

Expected visibility:

```text
MSP role
   AND
eligible practitioner
   ↓
ADD NPP to Facility is visible
```
